**Upstream:** docs(mcp): clarify example and component tool descriptions

**Decision:** port — five tool descriptions of six changed files. The sixth,
`docs/content/docs/1.getting-started/7.ai/1.mcp.md`, has no counterpart:
`7.ai/` here holds `2.llms-txt.md` and `3.skills.md`, and no page in
`docs/content/` lists the MCP tools.

These strings are what an agent reads to decide which tool to call and what it
will get back, so each was checked against this fork's handler rather than
copied:

| tool | what the handler actually returns here |
| --- | --- |
| `b24-ui-get-example` | `result.code` — a string, no metadata. Upstream's "code as a string only" is exact. |
| `b24-ui-list-examples` | `listComponentExamples()`, which is `return names` (`docs/modules/component-example.ts:156`). Names only. |
| `b24-ui-get-template` | the matching item from `templates.yml`: `title`, `description`, `framework`, `features`, `links` (Preview), `open_links` (GitHub, v0) and `deploy_links` (Vercel, Netlify). No setup instructions or code. |
| `b24-ui-get-component` / `-metadata` | unchanged behaviour; only the "use the other one when…" pointer is added. |

## b24ui adaptation

- "Nuxt UI" → "Bitrix24 UI"; every cross-reference renamed to this fork's tool
  names (`list-examples` → `b24-ui-list-examples`, etc.). All five
  cross-references were resolved against `docs/server/mcp/tools/*.ts`; each
  names a file that exists.
- `b24-ui-get-template` also mentions **one-click deploys**: this fork's
  template items carry `deploy_links`, which upstream's do not, and the handler
  returns the whole item.

## Observed, not changed

`templates.yml` lists `Dashboard` and `Starter` twice each — a `nuxt` and a
`vue` item under the same title — and the handler takes the first title match,
so the `vue` variants are unreachable through this tool. Upstream has the same
shape (`Chat`, `Dashboard`, `Starter` duplicated) and the same `.find()`, so
this is a shared limitation of the tool, not drift. The returned item does
include `framework`, so an agent can at least see which one it got.

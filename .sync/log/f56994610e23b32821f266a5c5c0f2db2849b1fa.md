## Upstream change

Two files under `docs/app/components/og-image/`. The fix adds explicit zero
widths — `border-t-0 border-x-0`, `border-y-0 border-l-0` — beside each
`border-solid`, with a comment giving the reason: takumi renders without a
preflight reset, so `border-solid` styles all four sides and any side with no
explicit width falls back to the CSS default of 3px. The result was stray borders
on the generated cards.

## Why it does not apply

`docs/app/components/og-image/` does not exist here — checked by listing rather
than by grepping for a component name. Nor does anything else: no `takumi` string
anywhere under `docs/app`, `docs/nuxt.config.ts` or either manifest, and no
`defineOgImage` call in any page. This fork does not generate OG images, so there
is no template to carry the fix into.

**Worth keeping even though nothing is taken.** The underlying trap is not
specific to takumi's templates: any renderer without Tailwind's preflight gives
`border-solid` a 3px default on the sides a class does not set. If OG image
generation is ever added here, that is the first thing to get wrong, and this
entry is where the answer already is.

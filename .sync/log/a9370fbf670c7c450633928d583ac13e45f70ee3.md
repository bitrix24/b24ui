Upstream adds `variant="outline"` to `InputFloatingLabelExample.vue`, so the
example keeps working when an app sets a different global `variant` default:
the label's background chip only matches the field in `outline`.

This fork's `Input` has **no `variant` axis**. Its theme's variants are `size`,
`color`, `rounded`, `noPadding`, `noBorder`, `underline`, `leading`, `trailing`,
`loading`, `highlight`, `fixed` and `type`, and `defaultVariants` sets only
`color` and `size`. `variant="outline"` would be an unknown attribute falling
through to the root element. The example file exists here, but there is nothing
to pin.

# Port: fix(SelectMenu): keep menu open when focus moves outside (#7095)

**Upstream:** `26016e8d4242426c3f1085a20eb7c33f55f92360` (nuxt/ui)
**Decision:** port — direct 1:1

## Upstream change
The SelectMenu content's `FocusScope` uses `loop` rather than `trapped`, so focus moving outside the open menu closed it. One example is another overlay restoring focus to its own trigger.

The fix adds an `onFocusOutside` handler on `ComboboxContent`:
- It only acts while the menu is open (`data-state="open"` on the scope's parent) and the event is not already prevented.
- It prevents the dismissal.
- It moves focus back to the search input, or to the scope itself when search autofocus is disabled.

`FocusScope` gets a `ref="focusScopeRef"` (via `useTemplateRef`) to locate that element. A new spec test, "stays open when focus moves outside", covers it.

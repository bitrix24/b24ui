# Port: feat(FileUpload): add `reject` event for dropped files (#7164)

**Upstream:** `c8f5ffc69430a77da34e498337f8e93a6dced4a9` (nuxt/ui)
**Decision:** port

## Upstream change
Before this commit, `useFileUpload` turned `accept` into a `dataTypes` list for
`useDropZone`. That list kept only MIME entries (`image/*` became `image`) and
dropped extension entries, because a drag exposes no filename. Upstream removes it:
- `useFileUpload`: `parseAcceptToDataTypes` is replaced by `isFileAccepted`. It
  checks each released file against `accept` by exact MIME type, by `type/*`
  wildcard, or by extension (case-insensitive), and `*` / `*/*` allow everything.
  Only drops are checked. The dialog already filters natively. Files that do not
  match are left out and passed to a new optional `onReject` callback. If nothing
  matches, `onUpdate` is not called. The filter runs before the
  single-file truncation. `useDropZone` no longer receives `dataTypes`.
- `FileUpload`: adds a `reject: [files: File[]]` emit, wired through `onReject`,
  which does nothing while the component is disabled.
- Docs: a "With rejected files" section with the Soon badge, plus a
  `FileUploadRejectExample` that shows a toast.
- Tests: a `reject event` case in `FileUpload.spec.ts`. The `accept parsing` block
  in `useFileUpload.spec.ts` is rewritten as `accept`, which drives `onDrop`
  and the dialog callback directly.

## b24ui port
- `src/runtime/composables/useFileUpload.ts`: the logic is ported verbatim. The fork
  has a JSDoc block on `useFileUpload` that upstream lacks, and it described the old
  behaviour ("the drop zone gets the MIME half … an `accept` written purely as
  extensions leaves the drop zone accepting anything"). That paragraph is rewritten
  for the new matching, and an `@param options.onReject` line is added. `computed` is
  still imported, since the returned `input` uses it.
- `src/runtime/components/FileUpload.vue`: the emit, the `onReject` option and the
  `onReject` function are ported verbatim. The fork's `disabled` computed has the
  same shape (`formFieldDisabled ?? props.disabled`).
- `docs/content/docs/2.components/file-upload.md`: upstream's section is added
  verbatim, Soon badge included.
- `docs/app/components/content/examples/file-upload/FileUploadRejectExample.vue`:
  `UFileUpload` becomes `B24FileUpload`. `icon="i-lucide-image"` becomes
  `:icon="ImageIcon"` (`@bitrix24/b24icons-vue/outline/ImageIcon`, the same icon the
  form-validation example already uses). Toast `color: 'error'` becomes
  `'air-primary-alert'` per `color-map.json`.

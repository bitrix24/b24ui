# port — nuxt/ui@42ba53272e84a316d6ea06ef7ab9a56b8afcb1ef

**Upstream:** fix(module): detect kebab-case components in Pug templates (#7045)

**Decision:** port.

`experimental.componentDetection` finds kebab-case usage only as `<b24-button`,
so a Pug template (`b24-card(...)`, `b24-card: b24-badge`, `#[b24-button …]`) was
invisible to it and those components shipped without their CSS. Upstream widens
the kebab alternative of `createComponentPattern` to also match at the start of a
line, after `: ` and inside `#[`, and adds the `m` flag so `^` means line start.

The fork's `createComponentPattern` matched upstream's line for line apart from
the prefix (`B24` / `b24-`), so the regex and the doc comment were carried as is.
Both adapters get it: the Nuxt module through `src/templates.ts` and the Vue
plugin through `src/plugins/templates.ts` both call `detectUsedComponents`.

**Deviations:** the spec case uses the fork's prefix (`b24-*`, `'B24'`) and a
neutral `<div />` fixture instead of upstream's `<UIcon …/>`. Verified it fails
with the `src/utils/components.ts` change reverted.

# port — nuxt/ui@384fdc12591a3124653438ec361438610b3dfe07

**Upstream:** fix(Form): merge unnamed nested forms into a parent without schema (#7034)

**Decision:** port.

With `transform`, `_validate` merges each nested form's output into the parent's
`transformedState`. A parent with no `schema` (or only a `validate` function)
never produces one, so `transformedState.value` is `undefined`: the unnamed
nested form's `Object.assign(undefined, …)` threw, and the submit handler never
received the nested transform. Upstream merges into a copy of the raw state
(`{ ...toRaw(state.value) }`) when there is no parent output yet, and returns
that.

The fork's transform block matched upstream's pre-image exactly, so the change
was applied as is, with upstream's fixture (`FormNestedTransform.vue`, `UForm`
→ `B24Form` imported from `#components` as the other Form fixtures do) and both
spec cases. Verified both fail with the `Form.vue` change reverted.

**Deviations:** none beyond the §1 rename in the fixture.

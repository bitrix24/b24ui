# skip — nuxt/ui@4fe6b29c8ff427694174d2d34ab1062795d16588

**Upstream:** docs(Chat): keep page context in history so the prompt cache holds

**Decision:** skip — the pre-image does not exist here, the change loosens a
guard this fork deliberately has, and its motivation is specific to a provider
this fork's docs chat does not use.

## What upstream changed

Upstream's pre-image appended a `[Context: the user is currently viewing …]`
marker to the **last** user message, per request, and never stored it. The
commit moves the path into each user message's `metadata`, re-attaches a marker
to **every** user message on every request so the history stays
byte-identical, and so keeps Anthropic's cached prompt prefix valid across
turns.

## Why it does not apply

**1. Different pre-image.** This fork does not use a marker at all. It
interpolates the page into the **system prompt**:

```ts
${safeCurrentPage ? `\nThe user is currently viewing the documentation page at \`${safeCurrentPage}\`. …` : ''}
```

(`docs/server/api/ai.post.ts:74`), and the client is `new Chat({ … })` with
`currentPage` in the transport body, not `useChat()` with message metadata.
Nothing in upstream's diff lines up with that.

**2. It loosens a guard.** Upstream's new `safePagePath` accepts
`^\/[\w/-]*$` — any site path — where the old check, and this fork's, accepts
only `^\/docs\/[\w/-]*$`. Upstream's own comment names the path an indirect
prompt-injection surface. Here it sits in the system prompt, the most trusted
part of the request, which is the worse place for it to be widened. Not
something to take piecemeal.

**3. Provider-specific motivation.** The commit exists to keep Anthropic's
prompt cache warm. This fork's docs chat is `deepseek('deepseek-reasoner')` with
`providerOptions: {}`.

## Observed, not changed

DeepSeek does cache matching prompt prefixes automatically. Here the page line
sits inside the system prompt, after the framework paragraph and before the
guidelines and the whole message history — so a navigation changes the prompt at
that point, and nothing after it can match a cached prefix. The cache is defeated
here too, just in a different way. That belongs to the same
deliberate pass as the deferred AI SDK v7 migration (#635), where the chat's
server shape is being reworked anyway, not to a partial replay of this diff.

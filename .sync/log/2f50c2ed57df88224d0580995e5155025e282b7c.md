# port — nuxt/ui@2f50c2ed57df88224d0580995e5155025e282b7c

**Upstream:** fix(useOverlay): resolve every pending promise when reopened (#7057)

**Decision:** port.

Calling `open()` on an overlay that is already open used to overwrite its single
`resolvePromise`, so the promise returned by the first `open()` never settled.
Upstream replaces it with a `resolvers` array: `open()` pushes, `close()` drains
it with `splice(0)` and resolves every pending promise with the close value.

`src/runtime/composables/useOverlay.ts` matched upstream's pre-image line for
line (the fork only adds the JSDoc on the exported `useOverlay`), so the patch
applied verbatim, along with the new case in `test/composables/useOverlay.spec.ts`.

**Deviations:** none. The private field rename (`resolvePromise` →
`resolvers`) shows through the exported `Overlay` type, but nothing in `src/`,
docs or the playgrounds reads it and upstream did not mark it breaking; same
call here.

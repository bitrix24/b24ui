# Port: docs(nuxt.config): pre-bundle tiptap and zod deps

**Upstream:** `765a4f5a24593816c0fa585cd4abfbfe6af4670f` (nuxt/ui)
**Decision:** port. 14 of the 15 entries; `@tiptap/pm/view` only serves the AI completion example the fork removed

## Upstream change
`docs/nuxt.config.ts` adds 15 entries to `vite.optimizeDeps.include`:
`@tiptap/core`, `@tiptap/vue-3/menus`, `@tiptap/pm/view`,
`@tiptap/starter-kit`, `@tiptap/markdown`, seven `@tiptap/extension-*`
packages, `tiptap-extension-code-block-shiki` and `zod`. In dev, Vite
otherwise finds these on the first visit to an Editor or Form page,
re-optimizes, and reloads the page.

## b24ui port
`docs/nuxt.config.ts`: the same entries, in the same position (around the
existing `@tiptap/vue-3` / `@tiptap/suggestion` / `@tiptap/pm/state` group),
except `@tiptap/pm/view`. Each one is imported by something the fork's docs
site renders:
- `@tiptap/vue-3/menus`, `@tiptap/starter-kit`, `@tiptap/markdown`,
  `@tiptap/extension-{code,drag-handle-vue-3,horizontal-rule,image,mention,placeholder}`:
  imported by the Editor components under `src/runtime/`, root dependencies.
- `@tiptap/core`: `src/runtime/` and one docs example.
- `@tiptap/extension-emoji`, `@tiptap/extension-text-align`,
  `tiptap-extension-code-block-shiki`, `zod`: docs examples, declared in
  `docs/package.json`.

**Not ported:** `@tiptap/pm/view`. Upstream imports it only from
`docs/app/components/content/examples/editor/EditorCompletionExtension.ts`,
the Editor AI completion example. The fork removed that example on purpose
(`.sync/PORTING.md` §2, "This fork has no AI chat"), and nothing else in
`src/` or `docs/` imports `@tiptap/pm/view`.

The fork's custom `@bitrix24/b24icons-vue/*` block and the rest of the list
are untouched.

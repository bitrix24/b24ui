# port — nuxt/ui@aab2d10dad9dc811f4fb4abb88cd00514e6b1a30

**Upstream:** fix(SelectMenu): remove the inherited "Show popup" aria-label

**Decision:** port — the defect is here, measurably: `aria-label="Show popup"`
appears **53 times in each** of the two SelectMenu snapshot files.

## The defect

reka-ui's `ComboboxTrigger` hard-codes `aria-label="Show popup"`. An `aria-label`
beats every other naming mechanism, so a screen reader announced "Show popup"
instead of the `B24FormField` label the author wrote — on every SelectMenu in the
library.

## The fix

```diff
-v-bind="{ ...$attrs, ...ariaAttrs }"
+v-bind="{ 'aria-label': undefined, ...$attrs, ...ariaAttrs }"
```

`SelectMenu.vue:731`, the same line as upstream's. The `undefined` goes **first**
so a caller-supplied `aria-label` still wins — it is a default being cleared, not
a prop being blocked.

## Snapshots: 106 updated, and each one checked

`test:update` rewrites the whole suite, so accepting 106 changed lines on trust is
how an unrelated drift gets absorbed. Every pair was compared instead:

```
pairs: 106
pairs whose ONLY difference is the removed aria-label: 106
pairs differing by anything else: 0
```

and `aria-label="Show popup"` now appears **0** times in either file.

## Tests

| test | what it pins |
| --- | --- |
| does not inherit the Reka trigger label | the fix itself |

All three pass in both environments.

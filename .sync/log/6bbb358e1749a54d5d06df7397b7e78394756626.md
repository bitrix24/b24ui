# port — nuxt/ui@6bbb358e1749a54d5d06df7397b7e78394756626

**Upstream:** fix(Listbox): add accessible name to listbox (#7193)

**Decision:** port (adapted)

## Problem
`role="listbox"` is on `ListboxContent`, but `aria-label`/`aria-labelledby`/
`aria-describedby`/`aria-invalid` were bound on `ListboxRoot`, so the listbox
had no accessible name (the a11y test had to disable `aria-input-field-name`).

## Change
- **src/runtime/types/form.ts** — `FormFieldInjectedOptions.labelId?` (with JSDoc).
- **src/runtime/components/FormField.vue** — `<Label :id="`${ariaId}-label`">`;
  provides `labelId` when a label (prop or slot) is rendered.
- **src/runtime/composables/useFormField.ts** — returns `labelId`.
- **src/runtime/components/Listbox.vue** — root binds `omit($attrs, label+field
  attrs)`; content gets `pick($attrs, fieldAttrs)` + `ariaAttrs`,
  `aria-required`, `aria-label`, and `aria-labelledby` (explicit attr, else the
  FormField `labelId` unless `aria-label` is set).
- **test/components/Listbox.spec.ts** — a11y test now asserts attrs land on the
  listbox and runs axe without disabled rules; added "is labelled by the form
  field label" and "is described by the form field error".

## Adaptations
- Kept the fork's `describedBy`-based `ariaAttrs` and `describedBy` injection
  field; `labelId` is added alongside them.
- Fork's Listbox has no `formFieldColor` destructure; only `labelId` added.
- Upstream `AuthForm` snapshots do not apply (component absent in fork).
- Snapshots (FormField, Listbox, and any spec rendering a labelled FormField)
  need regeneration — not hand-edited.

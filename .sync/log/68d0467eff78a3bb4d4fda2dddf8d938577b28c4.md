# port — nuxt/ui@68d0467eff78a3bb4d4fda2dddf8d938577b28c4

**Upstream:** perf(components): pick link props without a reactive proxy (#7208)

**Decision:** port

## Problem
`pickLinkProps` returned a `reactivePick` proxy, so every key read went through
another proxy layer on top of `useComponentProps`; template callers built a
fresh proxy on every render.

## Change
- **src/runtime/utils/link.ts** — `pickLinkProps` copies matching keys
  (`linkKeys` set, `aria-*`, `data-*`) into a plain object; drops the
  `@vueuse/core` import.
- **src/runtime/components/Button.vue** — `useForwardProps(computed(() => pickLinkProps(props)))`
  so the plain snapshot stays reactive.

## Adaptations
- Fork keeps its JSDoc on `link.ts` (adjusted the `reactivePick` mention, noted
  the plain-snapshot return). Upstream's Button comment not carried over (fork's
  Button had no such comment).
- Other fork callers (Breadcrumb, NavigationMenu, PageLinks, FooterColumns,
  ContextMenuContent, DropdownMenuContent, CommandPalette) call `pickLinkProps`
  inline in `v-bind`, re-evaluated each render — no change needed, same as upstream.

# Port: fix(ChatMessages/ChatPromptSubmit): add accessible names to icon buttons (#7153)

**Upstream:** `3cd30e013affa172acc2048710109690d83b042c` (nuxt/ui)
**Decision:** port

## Upstream change
Three icon-only buttons in the chat components now have accessible names:
- `ChatMessage`: each action button gets `:aria-label="action.label"`. Before this,
  the label was only shown in the tooltip. The `actions` JSDoc now says so.
- `ChatMessages`: the auto-scroll button gets `aria-label` set to
  `t('chatMessages.autoScroll')`. This adds `useLocale`.
- `ChatPromptSubmit`: the `aria-label` now depends on `status`. `ready` uses
  `chatPromptSubmit.label`, `submitted` and `streaming` use `chatPromptSubmit.stop`,
  and `error` uses `chatPromptSubmit.reload`. Before, every status used
  `chatPromptSubmit.label`. `$attrs` is still spread last, so a consumer's
  `aria-label` still wins.
- `Messages` gets three new keys: `chatMessages.autoScroll`, `chatPromptSubmit.reload`
  and `chatPromptSubmit.stop`. Every upstream locale has them.
- New tests in `ChatMessage.spec.ts`, `ChatMessages.spec.ts` and
  `ChatPromptSubmit.spec.ts`. The `ChatPromptSubmit` snapshots now show the new
  labels for the `error`, `streaming` and `submitted` statuses.

## b24ui port
- `src/runtime/components/ChatMessage.vue`: the JSDoc change is ported verbatim.
  `:aria-label="action.label"` goes on the `B24Button` inside `B24Tooltip`, after the
  fork's `color="air-secondary-no-accent"` and before `v-bind="omit(action, ['onClick'])"`.
  That is the same position as upstream, so an explicit `aria-label` in an action still
  overrides it.
- `src/runtime/components/ChatMessages.vue`: `useLocale` is imported, `const { t } = useLocale()`
  is added, and `:aria-label="t('chatMessages.autoScroll')"` is set on the auto-scroll
  `B24Button`. It sits before the `v-bind` of the `autoScroll` object, as upstream does.
- `src/runtime/components/ChatPromptSubmit.vue`: the `ariaLabel` computed is ported
  verbatim and used for `'aria-label'` in the `v-bind` object. **Adaptation:** the fork
  also had a separate `:aria-label="t('chatPromptSubmit.label')"` after the `v-bind`
  object. Vue merges bindings in order, so that later binding overrode both
  `...$attrs` and the new per-status label. It is removed. Without that, neither
  upstream test ("sets aria-label when status is …" or "allows overriding
  aria-label through attrs") could pass.
- `src/runtime/types/locale.ts`: the three new keys are added, using upstream's layout.
- Locales: every b24ui locale has an upstream counterpart. Each file gets upstream's
  strings verbatim, placed in the fork's key order (`chatMessages` before `chatPrompt`).
  The `label` values that already existed are not changed. For example, b24ui `en`
  keeps `'Send'`, while upstream uses `'Send prompt'`.
  - Same filename upstream and in b24ui: `ar`, `de`, `en`, `fr`, `id`, `it`, `ja`,
    `ms`, `pl`, `ru`, `th`, `tr`.
  - Same language under a Bitrix24 portal code: `br`↔`pt_br`, `la`↔`es`, `in`↔`hi`,
    `kz`↔`kk`, `sc`↔`zh_cn`, `tc`↔`zh_tw`, `ua`↔`uk`, `vn`↔`vi`.
  - b24ui only: none.
  - Upstream only, not adopted (§2 Locales): the other locales this commit touches
    (`az`, `be`, `bg`, `bn`, `ca`, `ckb`, `cs`, `da`, `de_ch`, `el`, `et`, `eu`, `fa_ir`,
    `fi`, `gl`, `he`, `hr`, `hu`, `hy`, `is`, `ka`, `km`, `ko`, `ky`, `lb`, `lo`,
    `lt`, `lv`, `mn`, `nb_no`, `nl`, `pt`, `ro`, `sk`, `sl`, `sq`, `sv`, `tg`,
    `ug_cn`, `ur`, `uz`).

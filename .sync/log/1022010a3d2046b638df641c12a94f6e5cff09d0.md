## Why the v7 note is false

Upstream migrated its chat code to v7 idioms in nuxt/ui@dfbbfeb (#6636). This
fork **deferred** that migration by maintainer call (#238, ledger `dfbbfeb5`,
decision `skip`), recording *"b24ui stays on ai@6"*.

The package did not stay on 6 — the alignment in #425 moved the catalog to
`ai: ^7.0.107`. So the code runs on v7, through v7's deprecated shims. Checked
against the installed `ai@7.0.107` types:

- `system` — `@deprecated Use instructions instead`
- `toUIMessageStreamResponse()` — `@deprecated … This method will be removed in
  the next major release`

"Targets v7" would describe code that is written for v6 and survives on v7.

Filed as #635: the deferred migration, with the full list of affected files.
Once that lands, this commit's note becomes true and can be taken then.

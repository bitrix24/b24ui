## Why the fallback is reachable here

Not asserted — the type says `'xss' | 'xs' | …`, which would suggest it is not.
But `TVConfig` lets `app.config.ts` add `variants`, so a size key added there
reaches `getEstimateSize` as an ordinary string with no entry in the table.

**Measured rather than reasoned about.** Calling the pre-image with a size
outside the table returns:

```
{ value: undefined, type: 'undefined', plusTen: NaN }
```

`estimateSize` is arithmetic input for `@tanstack/vue-virtual`, so `undefined`
does not degrade to a default — it poisons every offset after it and the list
stops positioning. That is the difference between "a row is the wrong height"
and "the list breaks", and it is why this is a fix rather than tidying.

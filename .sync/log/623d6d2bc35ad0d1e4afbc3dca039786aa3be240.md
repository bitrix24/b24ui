**Decision:** port (adapted).

## Change
- **src/runtime/utils/index.ts** — new exported `resolveAs(as, defaults)` (with
  JSDoc): a string / functional / render / setup component goes to `root`, an
  object is `defu`-merged over the defaults.
- `as` now also accepts an object targeting the heading element:
  - `DashboardNavbar` — `{ root: 'div', title: 'h1' }`
  - `Empty` — `{ root: 'div', title: 'h2' }`
  - `Error` — `{ root: 'main', statusMessage: 'h1' }` (dropped the `as: 'main'`
    `withDefaults` entry; the default now lives in `resolveAs`)
  - `FooterColumns` — `{ root: 'nav', label: 'h3' }` (dropped `withDefaults`;
    jsDoc `@defaultValue` corrected to `'nav'`)
  - `PageHeader` — `{ root: 'div', title: 'h1' }`
  - `PageSection` — `{ root: 'section', title: 'h2' }` (dropped `as: 'section'`
    from `withDefaults`)
  The hard-coded `<hN>` became `<Primitive :as="as.<slot>">`.
- **Avatar.vue** — inline resolver replaced by `resolveAs`; `defu` import removed.
- **Tests** — `with as object` `renderEach` cases on the six specs;
  `test/utils/resolve-as.spec.ts` copied verbatim.
- **Docs** — `::tip` under the Title / Error / Columns section of the six pages.

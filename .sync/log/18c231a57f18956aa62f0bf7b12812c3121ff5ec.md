# Port: chore(deps): update `@nuxtjs/mdc` to ^0.23.1

**Upstream:** `18c231a57f18956aa62f0bf7b12812c3121ff5ec` (nuxt/ui)
**Decision:** port

## Upstream change
Four files, but only one is a version number:

- `docs/package.json` — `@nuxtjs/mdc` ^0.22.2 → ^0.23.1;
- `pnpm-workspace.yaml` — a new `"@nuxt/content>@nuxtjs/mdc": ^0.23.1` override,
  and `@nuxtjs/mdc@0.23.1` appended to `minimumReleaseAgeExclude`;
- `renovate.json` — drops the `"allowedVersions": "<0.23.0 || >0.23.0"` rule
  that had been blocking exactly 0.23.0.

The override carries upstream's own reasoning: `@nuxt/content` caps
`@nuxtjs/mdc` at `^0.22.2`, so bumping only `docs` installs a **second** copy,
and component-meta then reads different components than the ones the module
registers.

## b24ui port
Verified the premise instead of trusting the comment: `@nuxt/content@3.15.2`
does declare `"@nuxtjs/mdc": "^0.22.2"` in its dependencies, and b24ui `docs`
sits on the same pairing (`@nuxt/content ^3.15.2` + `@nuxtjs/mdc ^0.22.2`). So
the transitive override is needed here for the same reason it is needed
upstream, and is ported verbatim, comment included.

After install `@nuxtjs/mdc` resolves to a **single** copy at 0.23.1 — without
the override it would have been 0.23.1 alongside content's 0.22.x.

### `minimumReleaseAgeExclude` — earlier note superseded
When `d7284f3` was processed the ledger recorded that b24ui has no
`minimumReleaseAgeExclude` block, so upstream's entries were treated as n/a.
That is no longer the whole picture: pnpm 11.20.0 applies a release-age
cooldown by default, and on this install it **created the block itself** and
appended `@nuxtjs/mdc@0.23.1` — the same entry upstream added by hand. It is
kept. (`@nuxt/icon@2.5.0` from `229b64f` remains correctly skipped: that
package is not in this tree at all.)

### `renovate.json`
Skipped, consistently with `229b64f`: b24ui has no renovate, and
`.github/dependabot.yml` is deliberately `github-actions`-only. There is no
`allowedVersions` rule here to remove — the rule upstream is deleting is one
this fork never had.

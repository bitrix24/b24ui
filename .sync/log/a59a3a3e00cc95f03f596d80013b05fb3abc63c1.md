# Port: fix(Form): accept empty values in `state` type (#7165)

**Upstream:** `a59a3a3e00cc95f03f596d80013b05fb3abc63c1` (nuxt/ui)
**Decision:** port

## Upstream change
`src/runtime/types/form.ts` gains a `FormState<S>` type: a deep version of the schema
input where every field may be `null` or `undefined`, and a number or bigint field may
also hold `''` (a cleared number input). Objects, arrays and tuples are walked
recursively. `Date`, `Blob`, `RegExp`, `Map`, `Set` and functions are leaves.
`FormProps.state` now uses `FormState<S>` instead of `Partial<InferInput<S>>`. The
`validate` param keeps `Partial<InferInput<S>>`. Type-only change, no runtime effect.

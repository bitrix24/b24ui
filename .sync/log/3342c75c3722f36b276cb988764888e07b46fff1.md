## What 4.5.2 contains
Checked the release rather than assuming. Nothing in it is a b24ui-specific
fix, but several entries are relevant to how this repository is built and
verified:

- **vite** — client manifest path, vite-node environment-API sourcemaps, worker
  build asset filenames;
- **nuxt** — client-side navigation for links inside islands, `definePageMeta`
  route-param types, island payload serialization for components with
  underscores, build output caching after Vue cache restoration, route rules
  matched against *decoded* paths, `asyncData` status settling when bailing;
- **kit** — nested `apply` / `applyToEnvironment` honoured in vite, plugin
  `enforce` handling in the vite wrappers, config cloning;
- **nitro** — island renders deduped during prerendering, `import.meta.test`
  for server code.

The nitro prerender dedupe and the vite manifest fix are the ones that touch
the docs build path this fork exercises out-of-band; nothing here required a
source change on our side.

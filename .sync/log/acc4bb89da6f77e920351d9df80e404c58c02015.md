## Lockfile, checked

`pnpm install` resolved `ai` to 7.0.118 (inside `^7.0.116`), pulled
`@ai-sdk/gateway` 4.0.96 / `provider` 4.0.18 / `provider-utils` 5.0.49 with it,
and `@nuxt/content` 3.16.1 brings its new dependencies `isomorphic-git`
1.42.2, `db0` 0.4.1, `nypm` 0.6.10, `pkg-types` 2.3.3, `confbox` 0.3.1 —
each traced to the 3.16.1 snapshot entry. The rest is `pnpm` / `@pnpm/exe.*`
12.6.0 and peer-suffix churn from `magic-string` 1.4.2. `pnpm-workspace.yaml`
was diffed after install: the installer did not touch it.

Two facts that look like drift and are not:

- **`@nuxt/content` 3.16.0 is still in the graph.** The root package declares
  it only as a peer (`^3`), so its auto-installed copy keeps the version the
  lockfile already held; docs and the playgrounds, which use the catalog, get
  3.16.1. `pnpm dedupe --check` would collapse it but would also rewrite
  dozens of unrelated entries (`tailwind-merge`, `postcss`, `unctx`…), which
  does not belong in a deps port.
- **`vite` still resolves to 8.2.1.** The `overrides.vite: ^8.2.1` entry
  (single rolldown ABI) governs resolution; the catalog value is kept in step
  with upstream but changes nothing installed — as with `^8.3.0` before.

# Port: fix(Kbd): avoid hydration mismatch for platform-specific keys (#7166)

**Upstream:** `78e72fb9b7a1012146f6713bba850f8024cbd8d5` (nuxt/ui)
**Decision:** port

## Upstream change
- `useKbd`: the shared composable no longer owns a reactive `meta`/`ctrl`/`alt` map filled in
  `onMounted` (that hook only ran for the first caller, so a Kbd hydrated after another had
  mounted rendered the resolved glyph on the client but `' '` on the server). The shared part
  now only computes `macOS` and adds `ui-macos` to `<html>`; `useKbd()` is a plain function
  that tracks *its caller's* mount with `useMounted()` and returns `' '` until then.
  New export `kbdKeysPlatformMap` (`{ macos, other }` per platform key).
- `Kbd.vue`: for `meta`/`ctrl`/`alt` renders both labels in two spans, toggled by
  `in-[.ui-macos]:*`; on the server it injects a static `useHead` inline script that sets
  `ui-macos` before hydration.
- `templates.ts`: the two `in-[.ui-macos]:*` classes join `prefixedClasses`.
- `Tooltip.vue`: `TooltipContent` gets an `aria-label` of text + resolved kbds (unless a
  `content` slot or explicit `ariaLabel` is given), since the two spans would otherwise read
  both labels.
- Tests in Kbd, Tooltip and useKbd specs; many snapshots updated.

## b24ui port
Applied 1:1 to `src/runtime/composables/useKbd.ts`, `src/runtime/components/Kbd.vue`,
`src/runtime/components/Tooltip.vue` and `src/templates.ts`, with `ui`→`b24ui` rewrites only.
- The class name `ui-macos` and head key `ui-kbd-macos` are kept verbatim (the fork already
  uses the `ui-` namespace for its CSS variables).
- The fork's jsDoc on `useKbd` is kept on the new `useKbd()` function and gains a sentence on
  the placeholder.
- `useHead` resolves through `#imports` in Nuxt and through `src/runtime/vue/stubs/base.ts`
  (`@unhead/vue`) for Vue, as `Banner.vue` already does.
- §5: the `useHead` `innerHTML` is a constant string with no interpolated input; annotated
  with a `SECURITY:` comment.
- The two new spans have no `data-slot`, matching upstream (keeps snapshot parity).

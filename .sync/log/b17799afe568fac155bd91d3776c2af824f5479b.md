# No-op: docs(app): move contribution to footer and add playground to navigation

**Upstream:** `b17799afe568fac155bd91d3776c2af824f5479b` (nuxt/ui)
**Decision:** no-op. This is upstream's docs-site navigation, and the fork's
site has none of the entries it rearranges.

## Upstream change
A rearrangement of ui.nuxt.com's navigation:
- **Contribution** leaves the Getting Started sidebar (`navigation: false` in
  `4.contribution.md`). It moves into the footer (`useFooter.ts`, between
  Blog and Team), the header link list and the search palette links
  (`useHeader.ts` and `useSearch.ts`, with a heart icon).
- **Playground** becomes a sidebar entry. A new `5.playground.md` links out to
  `https://play.ui.nuxt.com`, with a matching 302 `routeRule` and an
  `excludePrefixes` entry in `docs/nuxt.config.ts`. The footer's `/play` link
  is dropped, and the header and search entries point at the external URL.
- **Theme** gets a header and search entry (`/theme`). `figma.md` is renamed to
  `6.figma.md` to sort after Playground. The search palette's GitHub link loses
  `/releases`.
- A new root `CONTRIBUTING.md` points at the docs contribution guide.

## b24ui
Nothing applies:
- **Footer:** `docs/app/components/Footer.vue` renders a fixed set of buttons
  (REST API, Telegram, Releases) and a licence line, not a link list.
  `docs/app/composables/useFooter.ts` exists, but nothing in `docs/app` calls
  it. A Contribution entry there would render nowhere.
- **Header / search:** `useHeader.ts` and `useSearch.ts` carry the fork's own
  entries (Docs, Templates, Resources; Get Started … Typography, Templates,
  GitHub). There is no Blog, Team, Playground, Figma or Theme entry, so none of
  upstream's surrounding edits have anything to attach to. The search GitHub
  link already points at the repository root.
- **Playground:** the fork hosts no public playground (no `/play`, no
  `play.*` site). There is nothing for a `5.playground.md` link-out or its
  redirect to target.
- **Figma:** the fork has no `figma.md`, so there is nothing to renumber.
- **Contribution page:** with no footer link list and no header entry to take
  it, `navigation: false` on `4.contribution.md` would only remove the page
  from the sidebar and leave it reachable from nowhere on the site. It stays in
  navigation.
- **`CONTRIBUTING.md`:** the fork already has its own, b24ui-authored
  (it links the docs contribution guide and the `.github/contributing/`
  guides). Upstream's nuxt/ui text is not copied over it.

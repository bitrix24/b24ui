## Upstream change

`src/runtime/vue/components/Icon.vue` and its spec: the Vue-side `Icon` did not
render bundled icons during SSR.

## b24ui

**There is no `Icon` component in this fork at all.** `find src -name 'Icon.vue'`
returns nothing, and `src/runtime/vue/components/` holds only `color-mode`.

That is by design rather than by omission, and it is already recorded: the §1
component comparison added in #423 lists `Icon` and `prose/Icon` among the
nineteen names that exist only upstream. b24ui has no icon wrapper — icons are
`@bitrix24/b24icons-vue` components, imported and rendered directly, which is
why `data-slot="icon"` appears 6672 times across the snapshots and no component
ever passes a name string.

So there is no SSR path to fix. Nothing to port, nothing to adapt.

# port — nuxt/ui@57f7699315833854a4f4421c60763d365805e0e7

**Upstream:** fix(ChatPrompt): add `method="post"` to prevent input leaking via GET before hydration (#7078)

**Decision:** port. Security-relevant.

`ChatPrompt` renders a `<form>` whose submit is handled by `@submit.prevent`.
Before hydration that listener does not exist yet, so pressing Enter performs
the browser's default submission, which for a form without `method` is a GET to
the current URL: the prompt text lands in the query string, and from there in
history, server logs and `Referer` headers. Upstream sets `method="post"` when
the root renders as a form (the default `as`), so a pre-hydration submit at
worst POSTs to the page instead of putting the input in the URL.

The fork's root line matched upstream's apart from `data-slot="root"` (ours is a
literal, upstream reads `$attrs['data-slot']`), so the binding was added as is.
Snapshots updated: 22 roots per spec gain `method="post"`, same count as
upstream, no other change.

**Deviations:** none.

## The defect

A parent `<B24Form>`'s `dirty` looked only at its own `dirtyFields`. A change
inside a nested form never reached it, so a parent could report "nothing
changed" while a nested field had been edited. And a successful submit cleared
only the parent's own set, leaving the nested forms dirty.

## The fix

- `dirty` is true when the form's own fields are dirty **or** any attached
  nested form's `api.dirty` is.
- A nested form hands the parent a `clearDirty` when it attaches (added to
  `FormChildAttachEvent`), and a successful submit calls `clearDirty()`, which
  clears the form's own set and then every nested form's, recursively.

# Port: fix(Pagination): localize `aria-label` of controls and pages (#7151)

**Upstream:** `d2d3da0db012b8a21a003eace1b81f00e4135f32` (nuxt/ui)
**Decision:** port

## Upstream change
Pagination left its accessible names to Reka UI's built-in English defaults
(`First Page`, `Previous Page`, `Page N`, `Next Page`, `Last Page`), so they did not
follow the App locale. Now:
- `Pagination.vue` reads `t` from `useLocale()` and passes `:aria-label` to
  `PaginationFirst` / `PaginationPrev` / `PaginationNext` / `PaginationLast` and to each
  page `PaginationListItem` (`t('pagination.page', { page: item.value })`). The
  `PaginationListItem` tag is split across lines.
- `types/locale.ts` gains a `pagination` group: `first`, `last`, `next`, `page`, `prev`.
  Every upstream locale gains the five strings.
- `useLocale.spec.ts` gets a new case: under `<UApp :locale="de">` the seven buttons of a
  30-item Pagination carry the German labels.
- Snapshots: only the four control labels change case (`First Page` -> `First page`, etc.);
  `Page N` stays the same.

## b24ui port
- `src/runtime/components/Pagination.vue`: all hunks ported verbatim on the `b24ui`
  names (`b24ui.item(...)`, `props.b24ui?.item`).
- `src/runtime/types/locale.ts`: `pagination` added after `drawer`, which is a b24ui-only
  group between `modal` and `pricingTable`. Upstream adds it after `modal`.
- Locales: all 20 b24ui locales have an upstream counterpart. Upstream's strings were
  copied verbatim and inserted before `pricingTable`, mapped by language (b24ui code ->
  upstream: br->pt_br, in->hi, kz->kk, la->es, sc->zh_cn, tc->zh_tw, ua->uk, vn->vi;

  - Copied from upstream: ar, br, de, en, fr, id, in, it, ja, kz, la, ms, pl, ru, sc,
    tc, th, tr, ua, vn.
  - b24ui-only, translated or English fallback: none.
  - Upstream-only, ignored (no new locales, PORTING §2): az, be, bg, bn, ca, ckb, cs,
    da, de_ch, el, et, eu, fa_ir, fi, gl, he, hr, hu, hy, is, ka, km, ko, ky, lb, lo,

- `test/composables/useLocale.spec.ts`: upstream's case was ported with `B24App` and

- No docs change upstream.

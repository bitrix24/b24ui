# Port: feat(FileUpload): support custom file items in `v-model` (#6927)

**Upstream:** `a352073b458614937e489e5ec4770b00f75f4376` (nuxt/ui)
**Decision:** port

## Upstream change
- `FileUpload`: new exported `FileUploadItem` (`name`, `size?`, `type?`,
  `avatar?: AvatarProps`). Props/slots/model gain a second generic
  `T extends FileUploadItem = File`; the model and file slots are typed
  `T | File`. A `modelValue` prop is declared so `T` is inferred.
  `createObjectUrl` becomes `getFilePreview` (uses `avatar.src`, only creates an
  object URL for real `File`s), plus `getFileAvatar` (spread onto the leading
  Avatar when `fileImage` is on). The leading Avatar gets `alt=file.name`.
  `formatFileSize` tolerates a missing size. `onUpdate` is simplified around a
  `setModelValue` helper. `(file as File)` casts dropped.
- Docs: model description, two Soon-badged examples (custom items, upload status).
- Tests: type-inference tests, custom item rendering, alt text, `fileImage: false`,
  appending native files to custom items, keyed row state.

## b24ui port
- `src/runtime/components/FileUpload.vue`: ported verbatim modulo `ui`→`b24ui`,
  `appConfig.ui.icons.file`→`icons.file`, `size`→`props.size`. `FileUploadItem`
  got a JSDoc block (upstream has none). The fork's `onUpdate` has no
  `disabled` guard (upstream added it in an earlier commit not touched here); kept
  as is. The fork's `watch` keeps its `inputRef.value` check.
- Examples: `UFileUpload`/`UProgress`/`UButton` → `B24*`; types from
  `@bitrix24/b24ui-nuxt`. Icons via `icon-map.json`: `i-lucide-loader-circle` →
  `animated/LoaderWaitIcon` (the `animate-spin` `ui` override dropped; the glyph
  is animated), `i-lucide-circle-check` → `outline/CircleCheckIcon`,
  `i-lucide-x` → `outline/CrossMIcon`. `text-success` →
  `text-(--ui-color-accent-main-success)`; button `color="neutral" variant="link"`
  → `color="air-tertiary-no-accent" size="xs"`. Sample image `nuxt.png` →
  `bitrix24.png`.
- Docs: sections verbatim with Soon badges; Avatar link uses the fork's
  trailing-slash form.

## Tests
- `test/components/FileUpload.spec.ts`: upstream cases added. Fork differences:
  the fork's Avatar renders `data-slot="root"` (not `fileLeadingAvatar`), so
  selectors use `[data-slot="file"] img` and the Avatar is found by
  `findAllComponents({ name: 'Avatar' })` filtered on `closest('[data-slot="file"]')`;
  iconify strings replaced with the already-imported `SignIcon`/`Cross30Icon`.

Snapshots: `FileUpload.spec.ts.snap` and `FileUpload-vue.spec.ts.snap` change —
the file preview `<img>` gains `alt="file.txt"` (same as upstream).

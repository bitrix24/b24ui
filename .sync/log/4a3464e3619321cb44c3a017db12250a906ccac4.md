# Port: feat(NavigationMenu): add `viewport` prop (#7123)

**Upstream:** `4a3464e3619321cb44c3a017db12250a906ccac4` (nuxt/ui)
**Decision:** port

## Upstream change
Adds a `viewport` prop forwarded to Reka UI's `NavigationMenuViewport`
(e.g. `{ align: 'start' | 'center' | 'end' }`):
- `NavigationMenu.vue`: import `NavigationMenuViewportProps`, add
  `viewport?: Omit<NavigationMenuViewportProps, 'as' | 'asChild' | 'forceMount'>`
  after `contentOrientation`, `const viewportProps = toRef(() => props.viewport)`,
  and `v-bind="viewportProps"` on `<NavigationMenuViewport>`.
- Playground: a "Viewport align" select bound to `:viewport="{ align }"`.
- Docs: `### Viewport` section before `### Unmount`, with a warning that it only
  works with `orientation="horizontal"` and `content-orientation="vertical"`.

## b24ui port
- `NavigationMenu.vue`: same import, prop, `viewportProps` ref and `v-bind`
  (on `b24ui.viewport({ class: props.b24ui?.viewport })`). The fork has no
  `contentOrientation` / `arrow` props (see the `@memo` on
  `NavigationMenuProps`), so the prop sits after `content` and the JSDoc says
  "Only works when `orientation` is `horizontal`." — the fork's theme always
  positions the viewport with `left-(--reka-navigation-menu-viewport-left)` and
  `w-(--reka-navigation-menu-viewport-width)`, which is what upstream only does
  under `contentOrientation: 'vertical'`, so `align` takes effect in every
  horizontal menu here.
- reka-ui is pinned at `2.10.5`; its `NavigationMenuViewportProps` has
  `align?: 'start' | 'center' | 'end'` (default `'center'`), so no dependency
  move is needed.
- Playground: `B24Select` (size `xs`) for viewport align, shown in the `v-else`
  branch of the vertical-only controls (i.e. horizontal orientation), plus
  `:viewport="{ align: viewportAlign }"`.
- Docs: `### Viewport :badge{label="Soon"}` before `### Unmount`, reusing the
  fork's neighbouring Bitrix24 items (no icons, as in the sibling examples);
  `arrow` / `contentOrientation` dropped from the example props and the warning
  reduced to `orientation` `horizontal`, for the reason above.

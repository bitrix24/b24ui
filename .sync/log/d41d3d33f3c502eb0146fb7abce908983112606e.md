## Why it cannot be ported

`docs/content/showcase.yml` exists here, which is exactly why this needs saying
rather than passing as a mechanical skip. The file is not the same list. Ours
opens *"Check out some of the amazing projects built with **Bitrix24 UI**"* and
carries one entry. Upstream's is a list of sites built with **nuxt/ui**.

Appending their two entries would put sites that do not use this library on a
page claiming they do. That is not a port with an awkward fit — it is a factual
claim, and it would be untrue.

The screenshots are theirs for the same reason; there is nothing to render.

**Recorded rather than fixed:** our showcase has a single entry, and it points at
a Bitrix24 CRM page rather than a project built on this library. Whether that is
worth filling in is a maintainer's call about content, not something a sync can
decide.

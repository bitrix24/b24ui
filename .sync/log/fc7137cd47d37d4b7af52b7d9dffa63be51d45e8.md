# port — nuxt/ui@fc7137cd47d37d4b7af52b7d9dffa63be51d45e8

**Upstream:** fix(components): localize hardcoded accessibility labels (#7177)

**Decision:** port (adapted).

## Change
Hardcoded English accessibility strings now come from the locale:

| Component | Attribute | Key |
|---|---|---|
| Breadcrumb | root `aria-label` | `breadcrumb.label` |
| Calendar | `calendar-label` (day / month / year view) | `calendar.label` / `monthPicker` / `yearPicker` |
| CommandPalette | `ListboxContent` `aria-label` | `commandPalette.results` |
| InputDate / InputTime | segment `aria-label` (not for `literal`) | `inputDate.*` / `inputTime.*` |
| InputMenu | trailing trigger `aria-label` | `inputMenu.trigger` |
| InputNumber | input `aria-roledescription` (before `$attrs`, so callers override it) | `inputNumber.roledescription` |
| InputRating | indicator `aria-label` | `inputRating.rate` |
| PinInput | input `aria-label` | `pinInput.input` |
| Skeleton | `aria-label` | `skeleton.label` |
| Range | thumb `aria-label` via `thumbLabel()` (1 / 2 / n thumbs) | `range.thumb` / `min` / `max` / `value` |
| Stepper | root `aria-label` | `stepper.label` |
| Toaster | `ToastProvider` `label` (`props.label ?? …`; `label` no longer forwarded via `providerProps`) and `ToastViewport` `label` | `toaster.label` / `toaster.viewport` |

- **src/runtime/types/locale.ts** — new keys in existing sections (`calendar`,
  `commandPalette`, `inputMenu`, `inputNumber`) and new sections appended at
  the end of `Messages` (b24ui's order is not alphabetical).
- **src/runtime/locale/*.ts** — all 20 b24ui locales get every new key, with
  upstream's translation from the matching upstream file: `ar`, `br`←`pt_br`,
  `de`, `en`, `fr`, `id`, `in`←`hi`, `it`, `ja`, `kz`←`kk`, `la`←`es`, `ms`,
  `pl`, `ru`, `sc`←`zh_cn`, `tc`←`zh_tw`, `th`, `tr`, `ua`←`uk`, `vn`←`vi`. No
  locale added (§2 Locales invariant).

## Adaptations
- Upstream `Slider` is b24ui `Range` (§1): the locale section is `range`, not
  `slider`, matching the component's own key.
- `Carousel` is upstream-only — its hunk and the `carousel.roledescription` /
  `carousel.slide` keys are not ported (no consumer here).
- Tests: `Calendar.spec` (aria block), `CommandPalette.spec` /
  `DashboardSearch.spec` (dropped the `aria-input-field-name` axe exemption),
  `PinInput.spec` (`5 of 5`), `Range.spec` (test title), `Toast.spec` (label
  prop), `useLocale.spec` (per-component App-locale cases minus Carousel;
  `toaster: null` on the shared-`useLocale` case). New `findComponent` calls use
  `{ name: 'ToastProvider' }`; root-attribute checks use selectors.
- Upstream's `ContentSearch` snapshot change has no matching source change in
  this diff; nothing ported for it.

**Snapshots:** markup changes in Calendar, CommandPalette, DashboardSearch,
InputDate, InputMenu, InputNumber, InputTime, Range (+ others) — to be
regenerated with `pnpm run test:update`.

**Decision:** n/a.

Adds `.github/workflows/semantic-pull-request.yml`, running
`amannn/action-semantic-pull-request` on `pull_request_target` to require
Conventional Commit titles and posting a sticky comment on failure.

The fork already gates PR titles with its own `.github/workflows/pr-title.yml`
(the required `title` check), which goes further than a type allow-list: it
holds the type to `changelog-sections` in `release-please-config.json` and, via
`assert-commit-parses.mjs`, requires a port's subject to name the upstream
commit. A second, looser title check would add nothing and could disagree with
the first. Not adopted.

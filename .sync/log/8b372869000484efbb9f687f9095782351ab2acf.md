# Port: feat(Chart): new component

**Upstream:** `8b372869000484efbb9f687f9095782351ab2acf` (nuxt/ui, #7022)
**Decision:** port — full component, adopted by maintainer decision

## Upstream change

29 files. A new `Chart` built on TanStack Charts (`@tanstack/charts`, a new
**optional** peer): `line`, `area`, `bar` and `donut` types, stacking, three
curves, axes/grid/legend toggles, a `B24Tooltip`-based tooltip driven by
TanStack's focus events, a `#center` slot for donuts, a `#tooltip` slot, and a
`definition` escape hatch that takes a raw TanStack Charts definition. Plus
`utils/chart.ts` (monotone / step curve path builders), a six-step default
palette as CSS variables, docs, four examples, a playground page and the
manifest/lockfile changes for the new dependency.

## Adaptations

**Mechanical (§1).** `ui` → `b24ui` (prop, `appConfig.b24ui.chart`, every slot
call), `#build/ui/chart` → `#build/b24ui/chart`, `UTooltip` → `B24Tooltip`,
`tooltipUi` → `tooltipB24ui` (the comment explaining why it is bound on its own
still holds — the docs meta rewrites `b24ui` keys the same way). Locale
injection key in the spec: `Symbol.for('bitrix24-ui.locale-context')`.

**Series colours — a real adaptation.** Upstream resolves a colour name through
`appConfig.ui.colors` to `var(--ui-<color>)`, with `neutral` special-cased to
`var(--ui-bg-inverted)`. This fork has no runtime colour registry and no
`--ui-<color>` variables, so the names are a fixed own-key map
(`Object.hasOwn`, so a value such as `constructor` passes through as a CSS
colour instead of resolving through the prototype — tested):

| name | token |
|---|---|
| `air-primary` | `var(--ui-color-accent-main-primary)` |
| `air-primary-success` | `var(--ui-color-accent-main-success)` |
| `air-primary-alert` | `var(--ui-color-accent-main-alert)` |
| `air-primary-warning` | `var(--ui-color-accent-main-warning)` |
| `air-primary-copilot` | `var(--ui-color-copilot-accent-primary)` |
| `air-secondary-no-accent` | `var(--ui-color-base-1)` (upstream `neutral`, per `color-map.json`) |

Any other string is used as a CSS colour, as upstream. The tint for repeated
palette rounds mixes towards `var(--ui-color-bg-content-primary)` instead of
`var(--ui-bg)`.

**Default palette.** Upstream `--ui-chart-1…6` (`--ui-primary`, then Tailwind
blue/violet/amber/rose/cyan 500, redefined at 400 under `.dark`) becomes
`--b24ui-chart-1…6` in `:root, :host` under `@layer theme`:
`accent-main-primary`, `accent-main-success`, `copilot-accent-primary`,
`accent-main-warning`, `accent-main-alert`, `collab-accent-primary`. No raw
palette and no `.dark` block: the air tokens already switch across light / dark /
edge-light / edge-dark contexts. The fork's `--ui-color-palette-*` has only
blue/gray/green/orange/red, so upstream's hues are not reproducible one-to-one;
the six accents are the fork's distinct semantic hues.

**Theme (`src/theme/chart.ts`).**
- `root`: `text-xs` → `text-(length:--ui-font-size-xs)`; `text-muted` kept (a
  fork semantic utility). TanStack's own tooltip variables re-pointed at the
  `B24Tooltip` look: background/border `--ui-color-bg-content-inapp`, colour
  `--ui-color-base-8`, radius `--ui-border-radius-md`, shadow
  `--popup-window-box-shadow`, padding `6px 10px`.
- `base`: upstream's focus ring `outline-primary/25` + `ring-primary` becomes a
  2px outline in `--ui-color-design-outline-focused-stroke` (the focus token
  `test/utils/focus-accent-token.spec.ts` asks for); `rounded-md` →
  `rounded-(--ui-border-radius-xs)`.
- `tooltip` / `tooltipTitle` / `tooltipRow` / `tooltipValue`: the fork tooltip is
  a dark surface with its own text colour, so upstream's
  `text-highlighted` / `text-muted` (no `text-highlighted` exists here) become
  inherited colour with `font-(--ui-font-weight-medium)` and an `opacity-75` →
  `data-[active=true]:opacity-100` row emphasis. Also `justify-start min-h-0`
  and explicit padding to undo `B24Tooltip`'s row layout and 37px min-height.
- A header comment, as other fork theme files carry.

**Docs.** Front matter rewritten (description, GitHub/Demo/Nuxt UI/TanStack
Charts links with `iconName`/avatar), `navigation.badge: Soon` as upstream, plus
`:badge{label="Soon"}` on `## Usage` and on the new `## Chart` section of the
CSS variables page. Example colours: `success`/`error` → `air-primary-success`
/ `air-primary-alert`; `var(--ui-error|primary)` → accent tokens; `UBadge
variant="subtle"` → `B24Badge` (no `variant` here); `USeparator` →
`B24Separator`; `text-highlighted`/`text-muted` → fork typography utilities.

**Tests.** Colour names and the expected `var(…)` translated; `with neutral
color` → `with no-accent color`; `with ui` → `with b24ui`. Two cases added: air
names resolve to tokens while other strings (incl. `constructor`) pass through,
and the default palette is `--b24ui-chart-*`.

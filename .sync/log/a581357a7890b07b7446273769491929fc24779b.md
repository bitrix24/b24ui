## Why it does not apply

Neither half has a counterpart here.

**The removals.** This fork's `.github/workflows/` holds exactly `ci.yml`,
`deploy.yml`, `npm-publish.yml`, `pr-title.yml`, `release-please.yml`,
`release-watchdog.yml` and `smoke.yml`. There is no `stale.yml`, no
`reproduction.yml`, no `reproduire.yml`, and no `.github/reproduire/` directory.
Nothing is removed because nothing is there.

Checked by term rather than by listing, so the absence is not just a glance at a
directory. `triage` and `reproduire` match nothing anywhere under `.github/`.
`stale`, `reproduction` and `nuxi` do match, and every hit is incidental prose:
a comment and a warning string in `npm-publish.yml` about a stale *release*,
`stale` used in two contributing guides about out-of-date build output,
`reproduction` as a field in `ISSUE_TEMPLATE/bug-report.yml`, and `nuxi` inside
the advice to run `npx nuxi info`. No triage automation of any kind.

**The addition.** `.github/nuxi.yml` is not generic configuration that a fork
could adopt with renamed values. Every field names upstream:

- `package.name: "@nuxt/ui"` — ours is `@bitrix24/b24ui-nuxt`
- `maintainers: [benjamincanac]`
- `nextMajor: { label: v5, branch: v5, package: https://pkg.pr.new/@nuxt/ui@{sha} }`
  — this fork develops and ships from `main` and has no `v<N>` branches, which
  is the same reason `2aa1702a` (the `v5:` labeler rule) was recorded n/a
- `securityPolicy:` pointing at `nuxt/.github`
- `upstreams:` listing the repositories *they* track

And the bot itself would have to be installed on this repository for the file to
mean anything at all.

## Worth recording rather than acted on

The removed `stale.yml` closed issues after 60 days of inactivity, and this fork
has never had an equivalent. That is a deliberate-looking gap rather than a
defect, so nothing is proposed here — but if issue triage automation is ever
wanted, this commit is upstream's current answer to it, and the answer is a
third-party bot rather than a workflow that could be copied.

Same shape as `2aa1702a` (#596): an upstream `.github/` change whose subject is
their own repository's process.

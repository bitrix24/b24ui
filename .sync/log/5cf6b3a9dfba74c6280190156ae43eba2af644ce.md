# Port: fix(Chart): render tooltip above center slot

**Upstream:** `5cf6b3a9dfba74c6280190156ae43eba2af644ce` (nuxt/ui)
**Decision:** port — verbatim modulo §1 renames

## Upstream change

`Chart.vue` renders its tooltip in place (`portal: false`) inside the root, and
the `#center` overlay is `absolute inset-0`. With the overlay after the tooltip
in DOM order it painted on top of it, so on a donut with a `#center` slot the
tooltip disappeared under the centre content. The fix moves the `center` `<div>`
from after `<UTooltip>` to just after the TanStack chart, so the tooltip comes
later in the stacking order. Snapshots moved accordingly.

## Ported

The same move in `src/runtime/components/Chart.vue`, between the
`TanStackChart` and `<B24Tooltip>`. The only differences from upstream's diff
are the §1 renames already applied by the parent port (`b24ui.center`,
`props.b24ui?.center`, `B24Tooltip`).

## Adaptations

None beyond §1. The fork's `B24Tooltip` uses the same `TooltipPortal`
(disabled by `portal: false`) and the `center` slot classes are unchanged from
the parent port, so the stacking reasoning carries over as is.

## Not ported

Upstream's snapshot updates (`Chart.spec.ts.snap`, `Chart-vue.spec.ts.snap`) —
the parent port commits no Chart snapshots; they are generated on the first
test run.

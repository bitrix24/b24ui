# Port: feat(ContextMenu): add `open` and `pressOpenDelay` props (#7148)

**Upstream:** `73c489b64460430a0924e7897cfc33145e1458d0` (nuxt/ui)
**Decision:** port

## Upstream change
The reka-ui 2.11.0 bump (nuxt/ui@fa7a930) added `open` and `pressOpenDelay` to
`ContextMenuRootProps`, and upstream omitted both from `ContextMenuProps` at the time.
This commit un-omits them and forwards them:
- `ContextMenu.vue`: the `Omit<ContextMenuRootProps, …>` drops back to `'dir'` only.
  `rootProps` becomes `reactivePick(props, 'open', 'pressOpenDelay', 'modal')`. Together
  with the `update:open` emit, which was already there, `v-model:open` now works. reka
  anchors a programmatically opened menu to the trigger instead of the cursor.
  `pressOpenDelay` is reka's touch long-press delay (default `700`).
- `context-menu.md`: a "Control open state" section with a Soon badge and a
  `defineShortcuts` note, before "With custom slot".
- `ContextMenuOpenExample.vue`: a new docs example that toggles the menu with `O`.
- `ContextMenu.spec.ts`: a case where both props come from `<UTheme :props>`, and two
  `expectTypeOf` assertions on the prop types. No snapshots.

## b24ui port
- `src/runtime/components/ContextMenu.vue`: the same two one-line changes. They reverse
  the Omit the fork added in its own fa7a930 port, exactly as upstream does. The fork's
  `useComponentProps` returns `undefined` for a Boolean prop that is not passed. It does
  not cast it to `false`. So an uncontrolled ContextMenu still forwards no `open`, and
  `DropdownMenu` already forwards `open` the same way.
- `docs/app/components/content/examples/context-menu/ContextMenuOpenExample.vue`: a new
  file adapted from upstream's example:
  - The import is `@bitrix24/b24ui-nuxt`.
  - The icons are the `@bitrix24/b24icons-vue` set used by the fork's
    `DropdownMenuOpenExample` (`UserIcon`, `PaymentIcon`, `Settings3Icon`).
  - The prop is `:b24ui="{ content: 'w-50' }"`, the fork's dropdown width.
  - The trigger box classes come from the fork's `ContextMenuColorItemsExample`.
- `docs/content/docs/2.components/context-menu.md`: the section and note, verbatim except
  for the fork's trailing slash on `/docs/composables/define-shortcuts/` (as in
  `dropdown-menu.md`), placed before "With custom slot" as upstream has it.
- No playground change: upstream made none.

## Tests
`test/components/ContextMenu.spec.ts`:
- Upstream's new case, with `UTheme` renamed to `B24Theme`.
- The `expectTypeOf` import.

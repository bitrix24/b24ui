**Decision:** port

## Upstream change
- `docs/app/components/search/Search.vue`: the search index (SQLite wasm plus
  the docs dump) is no longer initialised on `onNuxtReady`; a watcher on
  `useContentSearch().open` calls `init()` on the first open (while `status`
  is `idle`) and flips an `opened` ref, so the modal is unmounted until then
  (`:unmount-on-hide="!opened"`) and stays mounted afterwards.

# port — nuxt/ui@04f253edb99d24993eb74bb83ca5418a77b24997

**Upstream:** fix(Drawer): don't disable body pointer events with `noBodyStyles` (#7150)

**Decision:** port

## Problem
reka-ui's modal `DialogContent` sets `pointer-events: none` on `<body>`, so
`noBodyStyles` (which only opts out of vaul's body styles) still left the page
non-interactive.

## Change
- **src/runtime/components/Drawer.vue** — `contentProps` defaults
  `disableOutsidePointerEvents: false` when `noBodyStyles` is set; an explicit
  `content.disableOutsidePointerEvents` still wins.
- **test/components/Drawer.spec.ts** — regression test reading
  `DialogContent`'s `disableOutsidePointerEvents` (uses `findComponent({ name })`).
- **docs/content/docs/2.components/drawer.md** — new "No Body Styles" section
  (with `Soon` badge) before Examples.

## Adaptations
- Docs example uses `<B24Button label="Open" />` / `:b24-button` (fork drawer
  docs style) instead of upstream's neutral/subtle button with a lucide icon.
- No snapshot changes expected.

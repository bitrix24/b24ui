## Upstream change

The re-render benches in `test/bench/button-link.bench.ts` and
`test/bench/link-stack.bench.ts` repeat their on/off cycle `CYCLES = 10` times
per call, with a comment explaining why: CodSpeed measures one call of the
bench body and adds a fixed ~150µs on some runs, which on a ~1ms body crosses
its 10% regression threshold.

## Why not here

Both files exist here (ported, with the fork's `B24*` names) and the change
would apply cleanly. But this fork does not run CodSpeed: nuxt/ui@8aa80416,
which wired it in, is a no-op here, and `bench` is a plain
`vitest bench --project vue` that no workflow invokes. Same reasoning as
nuxt/ui@3d2129d2, the identical change to `tv.bench.ts`, which is a skip.

Taking it would only make a deliberate local run ten times longer, and its
comment would describe a CI setup this repo does not have. Take it together
with 3d2129d2 the day benchmarks are wired into CI.

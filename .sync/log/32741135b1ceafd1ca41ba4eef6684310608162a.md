## Upstream change
Adds a `default` slot to InputMenu (slot props `{ modelValue, open, ui }`),
rendered right after the input and before the `leading` span — the same spot
Input's default slot occupies — so a floating `<label>` can be placed with
`peer` utilities. Adds an `InputMenuFloatingLabelExample.vue` docs example and a
"With floating label" section in `input-menu.md`; gives the Input floating-label
example an `id` / `for` pair. Snapshots: the existing "with default slot" test
now renders `Default slot` after the `<input>` (nuxt + vue).

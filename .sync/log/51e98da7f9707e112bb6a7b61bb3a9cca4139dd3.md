# port — nuxt/ui@51e98da7f9707e112bb6a7b61bb3a9cca4139dd3

**Upstream:** fix(DashboardSidebar/Header): use translated toggle label as menu dialog title (#7082)

**Decision:** port.

On mobile, `Header` and `DashboardSidebar` open their menu as a Modal / Slideover
/ Drawer titled `t('header.title')` / `t('dashboardSidebar.title')`. Those keys
are optional in `Messages` and no locale defines them, and `t()` returns the
key itself for a missing message — so the dialog's accessible name was the
literal string `header.title` (and its description `header.description`). The
snapshots showed it: `<h2 …>header.title</h2>`. Upstream reads the optional
messages directly and falls back to the toggle's own translated label
(`header.open` / `dashboardSidebarToggle.open`) for the title and to nothing for
the description.

The fork's `Messages` type has the same optional keys and none of its 21 locales
define them, so the bug was live here too. Applied as is (`useLocale()` returns
`locale` as a ref, unwrapped in the template). Snapshots: 14 updated, each
replacing the key with `Open menu` / `Open sidebar` and emptying the
description. Upstream's two spec cases added; both fail with the `src/` change
reverted.

**Deviations:** none.

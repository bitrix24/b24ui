# Port: feat(module): export prose components from `@nuxt/ui/components/prose` (#7143)

**Upstream:** `5c302c3bb83661226b74008a17741e8e001b3925` (nuxt/ui)
**Decision:** port (adapted)

## Upstream change
- **`src/runtime/components/prose/index.ts`**: a new barrel that re-exports every
  prose component as `Prose<Name>`.
- **`package.json`**: a `./components/prose` export (types + import) placed ahead of
  `./components/*`, plus a matching `typesVersions` entry.
- **`src/module.ts`**: the prose `addComponentsDir` call gets `extensions: ['vue']`, so
  Nuxt does not register the barrel as a component.
- **`src/plugins/components.ts`** (Vue adapter): a relative import that lands in the
  components directory now resolves by its path there before the basename fallback.
  Without this, `./Icon.vue` imported from the barrel would match the `Icon.vue`
  override instead of `prose/Icon.vue`.
- **Tests**: `test/components/prose/index.spec.ts` checks that the barrel exports every
  `.vue` file. A new `components-plugin.spec.ts` case covers resolution by path.
- **Docs**: a "With explicit imports" section in `4.typography/1.index.md`.

## b24ui port
- **`src/runtime/components/prose/index.ts`**: generated from the fork's own prose
  files rather than copied, because the sets differ. The fork has `H5` and `H6`;
  upstream has `CodeTree` and `Icon`. That gives 47 entries, sorted by export name
  the way upstream sorts them. The `callout/*` files are included.
- **`package.json`**, **`src/module.ts`**, **`src/plugins/components.ts`**: ported
  verbatim. In the plugin comment, `Icon` becomes `Link`, because this fork has no
  `Icon` component (see the note at the top of `components-plugin.spec.ts`).
- **`test/components/prose/index.spec.ts`**: verbatim. It derives the expected
  names from the files on disk.
- **`test/utils/components-plugin.spec.ts`**: upstream's case, with `Link` standing
  in for `Icon`. `../Link.vue` from `prose/A.vue` resolves by path to the
  vue-router override. `./Link.vue` from `prose/index.ts` names `prose/Link.vue`,
  which has no override, so it resolves to `undefined`; the old basename fallback
  would have returned the `Link` override.
- **Docs**: the section is placed after "With Prose components", with a Soon
  badge. Upstream's example passes the barrel to comark's `<Markdown>`, but this
  fork renders markdown through `<MDC>`/`ContentRenderer`. So the example shows a
  plain named import from `@bitrix24/b24ui-nuxt/components/prose` used directly in a
  template. Upstream's note that the `prose` option is still required is kept.

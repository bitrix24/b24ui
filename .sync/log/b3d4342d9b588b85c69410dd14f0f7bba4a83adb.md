# port — nuxt/ui@b3d4342d9b588b85c69410dd14f0f7bba4a83adb

**Upstream:** fix(InputMenu): prevent tags input from adding the search term on
enter (#6776)

**Decision:** port — same component, same `TagsInputRoot`/`searchTerm` wiring.

## The defect

In `multiple` mode reka-ui's `TagsInputInput` adds the search term as a tag when
Enter is pressed. But `TagsInputRoot` here is driven by the combobox, so that tag
never reaches `modelValue`: the user sees a chip that is not selected and cannot
be acted on.

## The fix

An `@keydown.enter` handler on the tags input that prevents the default, with an
early-out:

```ts
if (event.isComposing || !searchTerm.value) {
  return
}
```

## Coverage, including where it was NOT achieved

Upstream's two tests were ported and both pin real behaviour — one that no stray
chip appears, one that a highlighted item is **still** selected, so the fix does
not over-block.

**But the guard itself was uncovered.** Removing `if (event.isComposing ||
!searchTerm.value) { return }` left all 166 tests green — upstream's included. A
line nothing checks is a line that can be deleted in a future cleanup with a green
suite, so half of it is now pinned:

> `does not prevent enter when nothing has been typed` — green with the guard, red
> without it, and it is the only test that moves.

The reasoning behind it is real rather than defensive: with nothing typed there is
no tag to add, and preventing the key would also swallow the implicit form
submission an empty field allows.

**`event.isComposing` is still not covered, and the attempt is recorded rather
than hidden.** A probe constructing `new KeyboardEvent('keydown', { isComposing:
true })` reads the flag back as `true`, but the event is reported as prevented
anyway — `defaultPrevented` on that event is influenced by other handlers on the
same key, so the probe cannot attribute the outcome to this guard. Asserting on it
would have produced a test that passes for a reason unrelated to the line it
claims to cover. It is left uncovered and said so.

For the record, what the flag is for: during IME composition (Chinese, Japanese,
Korean) Enter confirms the candidate character. Swallowing it would break text
entry for those users.
